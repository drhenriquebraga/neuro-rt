# NeuroRT Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. Execução nesta sessão e pasta separada, conforme pedido do usuário.

**Goal:** entregar módulo independente instalável depois no Local Suite.

**Architecture:** HTML e API próprios, inferência em subprocesso, saída NIfTI
versionada e adaptador para engine.build_rtstruct do host.

**Tech Stack:** Python 3.10+, stdlib HTTP, Raidionics 1.5.2, SimpleITK, pydicom.

**Spec:** docs/superpowers/specs/2026-10-11-neuro-rt-design.md

## Global Constraints

- Sem alteração em AUTO_CONTORNO, sem dados de pacientes.
- Pedido explícito obrigatório; saída MR original, sem CTV/registro implícito.
- CPU padrão; erro explícito para CUDA indisponível.
- Pesos locais com pre_processing.ini; licenças incluídas.
- UNAPPROVED, procedência e frame da MR conferidos no RTSTRUCT do host.
