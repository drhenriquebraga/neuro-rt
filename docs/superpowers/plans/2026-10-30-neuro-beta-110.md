# NEURO RT 1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar cinco ferramentas de testes operacionais com Nidus revisável e instalação assistida recuperável.

**Architecture:** Host Local Suite8.12 controla fila, lifecycle, configurações e gravador RTSTRUCT. Plugin1.1.0 fornece catálogo/motores com mesmo Python, UI de testes, SDK transacional e recursos verificados. Manutenção ocorre em processo externo visível antes da reabertura da suíte.

**Tech Stack:** Python3.10+, FastAPI, NumPy/SimpleITK da base, workers ONNX/Torch/ANTs, JS e PowerShell existentes.

**Spec:** `docs/superpowers/specs/2026-10-30-neuro-beta-110.md`.

## Global Constraints

- Reusar Python e bibliotecas da suíte; nenhum CPython/venv novo nem downgrade da base.
- GitHub somente SETUP versionado e SETUP_LATEST; bundles offline apenas locais.
- RTSTRUCT UNAPPROVED por referência; sem CTV, fusão implícita ou inferência automática.
- Sem PHI nos testes/logs de entrega. Sem alterações das animações existentes.
- Modelo ambíguo avisa e permite; canal ausente desativa; nenhum AUTO/FAST por modelo.
- Host AUTO_CONTORNO pertence exclusivamente ao chat LOCAL SUITE I.

## Review Focus

- Orientação oblíqua e máscaras não cúbicas devem conservar coordenadas/SOPs na exportação.
- Cancelar o aceite, abrir URL direta ou usar API não deve iniciar execução sem aceite.
- Base3.10 com bibliotecas atuais deve funcionar sem trocar versões ao resolver extras.
- Rede bloqueada ou recurso parcial deve permitir fonte local verificada e retomada segura.
- Helper sem ack/reinício falho não pode derrubar a versão íntegra ou perder diagnósticos.
